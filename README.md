# Memory Cards

A simple Memory Card Game built using HTML, CSS and JavaScript.

This project was mainly created as a JavaScript practice project. The goal was to learn and apply JavaScript concepts by building an interactive game from scratch.

## How to Play

- Click on a card to reveal the emoji.
- Click another card to reveal its emoji.
- If both cards match, they remain flipped.
- If they don't match, they flip back after a short delay.
- Find all 8 matching pairs to complete the game.
- Try to complete the game in the fewest moves and shortest time possible.
- Use the Restart Game button to start a new game.

## Built With

- HTML5
- CSS3
- JavaScript

## Features

- 16 cards containing 8 matching pairs
- Randomized cards on every game
- Move counter
- Timer
- Matched cards remain revealed
- Prevents selecting a third card while two cards are being checked
- Restart button
- Basic responsive layout
- Card flip animation
